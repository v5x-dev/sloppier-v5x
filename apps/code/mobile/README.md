# v5x Code mobile

This is an empty Expo Router app for Code. It uses Expo UI and a development
client; the shared `@workspace/ui` package is web-only.

From the repository root, run `bun install`. From this directory, create and
install a development build with `bunx expo run:android` or `bunx expo run:ios`
(iOS builds require macOS and Xcode), then start Metro with `bun run start`.
Native directories are generated by Expo and are not maintained in this app.

Native components use Uniwind class names. The app imports Code's mobile tokens
from `@workspace/tokens`; see that package's README when changing the palette.
Restart Metro after changing `metro.config.js`.

The app includes Convex and the shared backend API, authentication and secure
storage primitives, the suite fonts, Phosphor icons, and `react-native-ble-plx`.
Bluetooth requires a development build, not Expo Go. Rebuild the native app
after changing native dependencies or config plugins. Android Bluetooth runtime
permissions and the native Brain transport still need to be implemented and
tested on hardware before Bluetooth can be used.

Before distributing builds, configure signing and build profiles and replace
the template icons. Authentication, Convex access, and Brain communication are not yet
implemented or configured.
