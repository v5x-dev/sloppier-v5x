# code (by v5x) Mobile

An empty Expo app for Code, using Expo Router and Expo UI.

From this directory, run `bun run android` or `bun run ios` to build and install a development client locally. Native build tools and a device or simulator are required. After installing the client, run `bun run dev` to start Metro. The `development` EAS build profile can also create an internal development build after the project is configured with EAS.

Routes live in `src/app`. Native projects are generated by Expo and are not checked in.

Uniwind is configured in `metro.config.js` and `global.css`. Its light and dark semantic color tokens mirror `@v5x/tokens/code/web.css`; update both when the Code palette changes.

Use `Text` and `TextInput` from `src/components/text` for app text and inputs. They apply the app-wide Merriweather font; explicit styles can override it. The font loads at startup on native and web.
