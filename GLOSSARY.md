# Program editing

## Language

**Workbench source**:
The files visible in an open program, including live drafts, their last committed text, and the identity of each file across moves and deletions.

**Live file session**:
One open editor's participation in a collaborative file, from opening and recovering local edits through synchronization, presence, and closing.

**Live document replay**:
Reconstruction of a collaborative file's current text from its ordered saved edits. A replay belongs to one version of the file; deletion and recreation create a different version.

**Source commit**:
A saved repository revision containing source file changes. Live synchronization and repository backups do not themselves commit the current source text.
