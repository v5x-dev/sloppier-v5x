# Programs

This context covers VEX V5 programs in the app, from their source files and collaborative editing through builds and transfers to a V5 Brain.

## Language

### Ownership

**Workspace**:
A personal or team space that owns Programs. Its members can work on every Program in it.

**Program**:
A named Workspace item for developing one VEX V5 robot program. It groups the source files and their committed history; its compiled output is a V5 binary.
_Avoid_: Project (when referring to the item in the app)

### Source

**Program template**:
A starter set of files and conventions used to create a Program. The app offers VEXcode, JAR, PROS, and EZ-Template templates.

**Program source**:
The files and current text being developed for a Program, including edits not yet committed. It excludes generated V5 binaries and dependencies supplied by the build environment.

**Live editing**:
Collaborative editing of a Program file by Workspace members. Edits synchronize across open editors, but remain uncommitted until captured by a source commit.
_Avoid_: Autosave

**Source commit**:
A saved revision of Program source that appears in its history. It captures the source at a point in time; later edits are not part of that revision.

### Building and upload

**Build**:
Compilation of a Program's committed source for the VEX V5 platform. Each build uses one source commit and produces diagnostics and, on success, one or more V5 binaries.

**V5 binary**:
A compiled `.bin` file generated by a successful build for a V5 Brain. It is build output, not Program source.

**Upload to V5 Brain**:
Transfer of a selected V5 binary to a slot on a connected V5 Brain. The upload can start the program after transfer.
