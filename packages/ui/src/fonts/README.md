# Web fonts

These files are subsets of the fontsource-variable packages that `@v5x/ui`
depends on (Merriweather, DM Sans, JetBrains Mono). They are generated by
`packages/ui/scripts/subset-fonts.py`. The build never runs the script. Rerun it
by hand and commit the output.

```sh
pip install fonttools brotli            # once
python3 packages/ui/scripts/subset-fonts.py            # default output
python3 packages/ui/scripts/subset-fonts.py --report   # sizes only, writes nothing
python3 packages/ui/scripts/subset-fonts.py --split-latin   # opt-in, changes rendering
```

Rerun when `@fontsource-variable/*` changes version (`bun.lock`), when a feature
list or weight range changes in the script, or when `CORE_CODEPOINTS` changes.
The script rewrites `styles/fonts.css`, so keep that file out of hand edits.

## What is here

- `<family>-<subset>.woff2`: one file per fontsource subset, in the order
  fontsource declares them. `fonts.css` lists each with its `unicode-range`.
- `licenses/<family>.txt`: each family's SIL OFL text, copied from fontsource.
- `lib/font-preloads.ts` (outside this folder): the preload links per route.

## Default output: identical rendering

Every subset keeps its glyphs, its declared `unicode-range`, and its place in the
CSS order, so browsers shape and fall back exactly as before. The output is
pruned:

- Layout features kept per family: `calt ccmp liga locl kern mark mkmk` (Merriweather
  also `tnum`, which the site uses with `tabular-nums`). Dropped: `dnom frac numr
  pnum`, which the site never enables.
- Named instances and the `STAT` table are dropped. Browsers do not read them for
  rendering.
- Glyph names are dropped (`post` format 3). Name records are cut to the family
  names and the copyright and license records.
- Merriweather has a Reserved Font Name under the OFL. Its subsets are renamed
  `v5x Serif Subset`. The copyright record is kept verbatim, as the OFL requires.
- `prep` and `gasp` are kept. No glyph has instructions, so the hinting tables are
  only 15 bytes per file. Removing them would save about 0.2 KB across the set and
  could change rasterization on platforms that run the TrueType interpreter, which
  I could not test here.
- The weight range is narrowed where advances stay exact. DM Sans is 400–1000 and
  JetBrains Mono is 400–800. Narrowing re-encodes the variation deltas, so outlines
  move by at most 0.35 font units (under 0.01 px at 16 px). Advance widths did not
  change at the weights the site uses. Merriweather stays 300–900: its default is
  300, and trimming the bottom moves the default, which shifts advances by one unit.
  DM Sans stays up to 1000 because cutting the top also shifts advances.

## Opt-in: `--split-latin` (changes rendering)

The latin subset becomes two files: `core` (printable ASCII and the common
punctuation) and `extended` (the rest of latin: Latin-1 and symbols).

The split cannot be pixel-identical. Latin-1 and Latin Extended-A glyphs kern
against ASCII in these fonts (3,775 ASCII-to-Latin-1 pairs in Merriweather alone).
Once the two halves are separate faces, those pairs lose their adjustment. For
example, "VÁ" in Merriweather moves by about 1.6 px at 16 px, and the "é" in
"Café" moves by up to 0.06 px. The screenshot diff on the fixture page changed
17,579 pixels (largest channel delta 227).

Sizes (decoded bytes):

| file | default | `--split-latin` |
| --- | ---: | ---: |
| merriweather latin / core + extended | 92,368 | 41,876 + 22,672 |
| dm-sans latin / core + extended | 22,852 | 14,872 + 9,776 |
| jetbrains-mono latin / core + extended | 29,632 | 24,124 + 8,088 |

Approve the split before committing its output. The script removes the other
mode's files, so run it only when you intend to change the committed set.

## Preloads

`lib/font-preloads.ts` maps each route id to the files it renders first. The
root route's `head` adds those links, because the leaf route's own `head` links
did not reach the server HTML (see the commit message). Login renders no text and
preloads nothing.

- `/`: Merriweather and DM Sans
- `/programs/$programId`: Merriweather and JetBrains Mono
- `/invites/$invitationId`, `/callback`: Merriweather

## Other files

- `vite-url.d.ts` declares `*.woff2?url` for the UI package, which does not
  reference `vite/client`.
- The app's Vite config never inlines `.woff2` files. An inlined font loads with
  the stylesheet on every page. `jetbrains-mono-cyrillic-ext` (1.1 KB) was inlined
  before.
